## A Text based game engine

I have always been fascinated by the idea of games, how the internal mechanisms click to make the game come alive. I think the 
fascination started when I gt my first laptop - a Dell Latitude D520. It had a Core 2 Duo processor and 1 GB of RAM, huge for the 
time I got it and not really enough for serious gaming.

The first game that I played on that machine was 'Archibald's adventures'. Prior to that I was only programming in C and C++ using 
Borland compiler. I was new to the Linux ecosystem and also games did not run natively on Linux at that time. I had thought of using
WINE, but that did not prove much useful for running games.

I had also read about the Text based game Zork and wanted to see how one could be made. So I thought of writing one myself.

#### Initial implementation

I had always thought of writing a game from scratch and after a long time, I think I am finally ready to go ahead and write the first 
draft version using a interpreted language. My final choice would be to use C/C++ to write the proper one, but at least on the laptop
which I use the most, I would be using Python for the initial implementation.
